# ⚽ Sistema de Gestão - Base de Futebol
Este é um sistema prático e intuitivo para o cadastro e gerenciamento de atletas de categorias de base. O projeto foi desenvolvido para facilitar a organização de elencos, permitindo o acompanhamento de categorias, posições e exportação de dados.

## 🚀 Funcionalidades
Cadastro Completo: Registro de nome, data de nascimento, posição e perna dominante.

Cálculo de Categoria: O sistema define automaticamente se o atleta é Sub-11, Sub-13, Sub-15, Sub-17, Sub-20 ou Profissional com base na idade.

Gestão de Fotos: Upload de fotos dos atletas via Base64 (armazenamento local).

Busca em Tempo Real: Filtro inteligente para encontrar jogadores rapidamente pelo nome.

Dashboard de Estatísticas: Resumo visual do total de atletas e distribuição por categorias.

Exportação em PDF: Geração de relatórios formatados para impressão ou compartilhamento.

Persistência de Dados: Utiliza LocalStorage para que as informações não sejam perdidas ao fechar o navegador.

## 🛠️ Tecnologias Utilizadas
HTML5: Estruturação semântica.

CSS3: Design moderno utilizando Flexbox e Grid Layout.

JavaScript (ES6+): Lógica de programação, manipulação de DOM e armazenamento local.
